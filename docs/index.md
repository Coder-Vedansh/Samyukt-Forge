# Welcome to Forge CLI

Forge CLI is the "Linux for AI" - a next-generation open-source developer platform that acts as the central nervous system for AI agents.

## Why Forge?
AI agents need more than just prompts. They need scheduling, long-running execution environments, memory, tools, and sandboxed plugins. Forge CLI provides a robust Microkernel architecture to manage all of these components seamlessly.

## Key Features
- **Microkernel Architecture**: Event-driven buses routing actions efficiently.
- **Plugin Sandbox**: Safely run untrusted 3rd-party plugins.
- **MCP Native**: Out-of-the-box Model Context Protocol support.
- **Async Runtime**: Parallel task execution, DAG scheduling, and Checkpointing.
