# Forge CLI

A next-generation open-source AI developer platform.

## Architecture

Forge CLI is built around a highly modular, decoupled Microkernel architecture.
It functions as a central nervous system for AI agents, providing scheduling, orchestration, and plugin sandboxing out of the box.

### Features
- Process-isolated Plugin Sandbox
- High-performance asyncio Task Runner
- Open Model Context Protocol (MCP) Support
- Robust Package Manager
