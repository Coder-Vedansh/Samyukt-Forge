# Security Policy

## Supported Versions

Only the latest major version of Forge CLI receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.9.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Forge CLI, please DO NOT open a public issue. Instead, send an email to `security@forge-cli.com`. 

All security vulnerabilities will be promptly addressed. We aim to acknowledge your report within 48 hours and provide a patch within 7 days.
